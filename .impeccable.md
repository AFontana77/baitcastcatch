# BaitCastCatch — Impeccable Design Context

## Design Context

### Users
Freshwater anglers — bass fishers, trout hunters, catfish guys who fish on weekends and want a real reference in their pocket. Phone on the tailgate or by the water. They're checking fish species before or after a trip, logging a catch while the memory is fresh, or verifying size limits before they keep a fish. Practical, outdoorsy, not interested in anything slow or decorative.

### Brand Personality
Three words: **precise, outdoorsy, practical.**

This is a field guide, not a fishing retail site. Think NOAA charts, state regulation booklets, laminated species ID cards. Zero decoration that doesn't carry data. The site should make an angler feel like they found the right reference — not like they landed on a Bass Pro Shops product page.

### Aesthetic Direction
**Light theme.** Outdoors, daytime, sun on the water. Dark would feel like a dashboard, not a field tool.

**Font pair:**
- Display: `Teko` — a condensed geometric sans that reads like a map legend, a field guide header, or a fishing regulation section label. Bold, utilitarian, technical. NOT a serif (cigars are for serifs; fishing is utilitarian). NOT Oswald or Bebas Neue (too overused in outdoor/sports contexts). Teko is precise without being aggressive.
- Body: `Karla` — a clean, slightly condensed humanist sans. Readable at small sizes, pairs with Teko without competing. Not a reflex pick — it's been used in data-forward contexts precisely because it's compact and legible.

**Color system (OKLCH, light):**
- Background: `oklch(0.99 0.005 240)` — near-white with blue-water tint
- Surface/card: `oklch(0.95 0.010 240)` — light blue-tinted surface
- Surface2: `oklch(0.92 0.015 240)` — medium tint for alternating sections
- Foreground: `oklch(0.15 0.025 240)` — near-black with blue tint
- Muted foreground: `oklch(0.48 0.018 240)` — mid gray-blue
- Border: `oklch(0.84 0.020 240)` — subtle blue-tinted border
- Primary (blue): `oklch(0.43 0.22 255)` — strong blue, readable on light
- Primary dark: `oklch(0.34 0.20 255)` — hover/pressed state
- Teal accent: `oklch(0.62 0.14 205)` — water teal for secondary actions

**Reference feel:** USGS field ID guides, FishBase species pages (data-first), NOAA regulation booklets. Anti-reference: Bass Pro Shops, Cabela's (retail), any fishing app with cartoon fish, anything with gear photos.

### Design Principles
1. **Data is the hero.** "375 species, size limits, state regulation links" — these facts should dominate the visual hierarchy, not fade into supporting copy.
2. **Utility over ornament.** Every element should have a clear functional purpose. If a decorative element can't be justified by usefulness, remove it.
3. **Split layouts, not centered.** Left text column, right data or visual column. Field guides don't center their text.
4. **Condensed type = more in less space.** Teko's condensed nature means more information per line, which suits a data-heavy reference tool.
5. **Replace cards with rows.** Feature content is displayed as clean horizontal rule-separated rows, not 2×2 icon cards.

### Layout direction for homepage
- Hero: Two-column split. Left: headline + subhead + CTAs. Right: a clean data table showing sample species entries (name, type, size limit) — demonstrate the product instantly.
- Middle section: Horizontal stat strip with large Teko numbers (375 species, 50 states, 0 subscriptions). Then a text section.
- Feature section: Clean list with horizontal rules, NOT icon card grid.
- CTA section: Blue-tinted panel. Clean, direct.
- Overall: Functional, information-forward, field-guide discipline.

### WCAG
Full WCAG 2.1 AA. All text on light blue-tinted backgrounds must pass 4.5:1. `oklch(0.15 0.025 240)` on `oklch(0.99 0.005 240)` is approximately 14:1.
